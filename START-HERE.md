# 💧 Welcome to Hydrate Together!

Hi! This is our water app. You don't need to know how to code to help build it.
**You describe what you want. AI agents build it. You say yes or no.** That's it.

---

## 1. One-time setup (about 5 minutes)

1. **Make a GitHub account** at <https://github.com/signup> (free). GitHub is just the
   website where the app's code and our to-do list live.
2. **Send your username** to your partner so they can invite you.
3. **Accept the invite.** It arrives by email ("You've been invited to collaborate…"). Click **Accept**.
4. **(Optional) Get the GitHub app** on your phone ([iPhone](https://apps.apple.com/app/github/id1477376905) /
   [Android](https://play.google.com/store/apps/details?id=com.github.android)). You can do everything below from it.

## 2. Try the app

Open the live app: **https://jnorwoo.github.io/hydrate-together/**

To put it on your home screen like a real app:
- **iPhone (Safari):** tap Share ⬆️ → *Add to Home Screen*
- **Android (Chrome):** tap ⋮ → *Install app*

## 3. Ask for a new feature 💡

1. Go to the repo → **Issues** tab → **New issue** → **💡 Feature idea**.
2. Describe it like you'd text a friend. For example, *"Can the reminder say something
   funny?"* or *"I want to see a little plant that grows when I drink."*
   Screenshots and pictures are welcome.
3. Click **Create**.

That's it! An agent might reply with a question or two. Just answer in a comment.

> **Using your Muse or Quokka agent?** You can also just tell them the idea and ask them to
> "open a GitHub issue for it in hydrate-together". Same result.

## 4. Get an agent to build it 🤖

On the issue, either:
- write a comment that says **`@claude please build this`**, or
- on the right side, click **Labels** → pick **`agent: claude`** (or **`agent: quokka`**).

The agent will comment that it's working on it. A few minutes later it opens a
**pull request** (a "PR"), which is basically *"here's my change, do you like it?"*

## 5. Say yes (or "not quite") ✅

Open the PR (you'll get a notification). Read **What changed** and **How to try it**.

- **Love it?** Click **Merge pull request** → **Confirm**. The live app updates in about 2 minutes. 🎉
- **Want changes?** Write a comment like *"@claude make the button pink"* and it'll update the PR.
- **Not sure?** Ask your partner to take a look. No pressure. Nothing breaks the live app until you merge.

## Words you'll see

| Word | What it means |
|---|---|
| **Repo** | The project folder that holds the app |
| **Issue** | A to-do card: an idea or a bug |
| **PR / Pull request** | An agent saying *"here's my change, want it?"* |
| **Merge** | Saying yes to a PR, which puts it into the real app |
| **Label** | A colored tag on an issue (e.g. `agent: claude`) |
| **`needs human`** | An agent is stuck and needs one of us to do something (often your partner) |

## Something broken? 🐞

Issues → New issue → **🐞 Something's broken**. Describe what happened. Screenshots help!
